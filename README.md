# NASA Exoplanet Archive - Data Cleaning & Analysis

Cleaning and analysing NASA's scientific exoplanet dataset with Python, turning raw archive data into a structured, analysis-ready dataset.

## What I did
- Cleaned and prepared the NASA Exoplanet Archive dataset (missing values, types, duplicates).
- Performed mathematical and physical calculations: orbital formulas, mass conversions, radius equations.
- Validated scientific variables and removed physically inconsistent records.
- Produced a structured, analysis-ready dataset and visual exploration of planet properties.

## Tools
Python - Pandas - NumPy - Matplotlib - Seaborn - Jupyter Notebook

## Project structure
```
nasa_exoplanet_analysis.ipynb   # full workflow: cleaning, calculations, validation, charts
data/Planets list.csv           # NASA Exoplanet Archive extract
requirements.txt
```

## Run it
```bash
pip install -r requirements.txt
jupyter notebook nasa_exoplanet_analysis.ipynb
```

## Data source
[NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/) (public data).
